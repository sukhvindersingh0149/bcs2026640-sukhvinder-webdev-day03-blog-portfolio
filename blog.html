Learning journal

Short notes about what I learn in web development, newest first.

17 November 2026

Links and images finally make sense

Today I built a site with three pages and connected them using the a tag. The most important thing I learned is the difference between a relative path like images/hero-code.svg and a full web address.

I also learned that every image needs an alt text, so people using screen readers know what the image shows.

10 November 2026

My first push to GitHub

Git saves my work in small steps. First I run git add to choose files, then git commit to save a snapshot, and finally git push to upload it to GitHub.

3 November 2026

Why I chose web development

I like that I can write a few lines, refresh the browser and see the result straight away. That quick feedback keeps me curious. My goal is to finish one small project every week.
